# PRACTICE TEST 2 – CFL Github Pages

All files in each ZIP must be uploaded **at the repository root** (`/`), without creating subfolders. Upload the extracted files, not the ZIP itself.

## Contents
- Listening: 35 questions in 3 parts, 14 original MP3 recordings, supplied scripts for teachers, 4 answer choices per question.
- Reading: 4 passages × 10 questions, 4 choices each. **No Vocabulary Warm-up or Paraphrase Challenge.**
- Learner: Check shows only correct/incorrect, with no visible Key/Evidence/Explain controls.
- Teacher: independent **Key**, **Evidence**, and **Explain** controls per question (explanations in English and Vietnamese). Highlight, Dictionary, font resizing, reset, and local progress are retained. Reading has a 15-minute timer per passage.

## Quality-control notes about the supplied test
The answer choices and texts otherwise follow the supplied `Session 2 June 12.docx` and the answers marked red/bold in `Session 2 June 12 - Key Script Sample.docx`.

- **Listening Q29:** The supplied key marks **D**, but the audio/script explicitly advises avoiding exercise before sleep. *Playing computer games* is not mentioned as a reason for poor sleep; the site's correct answer is therefore **B**. This is an explicit, documented correction to avoid wrong scoring.
- **Listening Q34:** The original question allowed **both A and B**: Finnish mythology mentions foxes and Inuit mythology mentions animal spirits. The website specifies **“what did Finnish people believe…”**, making **A** uniquely correct; answer choices remain unchanged.
- **Listening Q20:** The supplied key is **C**, but the wording "How did the man collect his needed information" is ambiguous: the librarian offers pre-existing scans, while the student has not yet accessed them. The site follows the supplied Key (**C**); please review this question before any high-stakes assessment.
- **Reading Q17:** The supplied correct answer A mentions outdated skills but omits the smaller social network also discussed. The site retains supplied Key **A**, with a warning in the teacher explanation.
- **Reading Q20:** Supplied Key **B** is retained; D also summarizes a major recommendation in the passage and should be considered if editing the test.
- **Reading Q6:** The original question depends on *printed line numbers*. A browser reflows text on different screens; the evidence is highlighted in Teacher, but learners should use the corresponding sentence in Passage 1 rather than treating Word line numbering as fixed.

The source includes several minor typos and potentially weak distractors. Apart from Q29's key and Q34's question wording, the question texts and choices have been preserved. These sites are for learning and review, not secure/proctored examinations: static JavaScript cannot hide the key from source-code inspection.

## Deploy
1. Create two separate GitHub repositories for Learner and Teacher versions, if preferred.
2. Upload **all files** extracted from the corresponding ZIP to the repository root.
3. In GitHub Settings → Pages choose Deploy from branch → main → /(root).
4. Reload the page after deployment. For audio, verify that all `P1.x.mp3`, `P2.x.mp3`, `P3.x.mp3` files are present and case-sensitive names match.
